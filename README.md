# LeetMetric

A clean, modern web application to track and visualize your LeetCode progress. Simply enter your LeetCode username to see your stats at a glance.

## 🚀 Features

### Visual Progress Circles

- **Easy, Medium, Hard** progress rings with animated fill
- Color-coded difficulty levels (Green, Yellow, Red)
- Shows solved/total count for each difficulty

### User Statistics

- **Username Display** - Shows the searched user's profile
- **Rank** - Your global LeetCode ranking
- **Problems Solved** - Total solved vs total available
- **Acceptance Rate** - Your submission success rate

### User Experience

- Clean, dark-themed interface
- Real-time data fetching from LeetCode API
- Responsive design for all screen sizes
- Smooth animations and transitions

## 🛠️ Tech Stack

- **HTML5** - Structure
- **CSS3** - Styling with modern features (SVG, flexbox)
- **JavaScript** - Vanilla JS for API calls and DOM manipulation
- **API** - LeetCode Stats API

## 📦 Usage

1. Clone the repository
2. Open `index.html` in your browser
3. Enter a LeetCode username
4. View the stats!
